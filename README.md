# Starlight Sanctuary ✦ A Transmission for Yangiee

An intimate 3D cosmic sanctuary & starlight goodnight web application built with WebGL (Three.js), HTML5 Canvas, Web Audio API, and GSAP.

## ✨ Features

- 🌕 **Procedural 3D Moon & Atmosphere**: Real-time rotating lunar surface with Rayleigh scattering atmosphere glow shader.
- ✨ **Twinkling Starfield & Constellation Map**: Interactive star nodes customized with memories for Yangiee.
- 🎵 **Generative Web Audio Synthesizer**: Pure Web Audio ambient soundscapes (*Lofi Night Beats*, *Soft Rain on Glass*, *Warm Fireplace Crackles*) with a live audio visualizer. Zero MP3 dependencies!
- 🌠 **Extravagant & Cute Meteor Shower**: Long-press "Blow Out the Stars" sleep blackout mode with shooting comets, trailing stardust, cute heart emojis (`💖`), and pentatonic chime cascades.
- 📱 **60fps Mobile Optimized & Gyroscope Support**: Hardware-accelerated rendering, DeviceOrientation gyro parallax, and touch haptics.
- 🕒 **Live Clock & Staggered GSAP Entrance**: Staggered UI entrance sequence and live ambient clock.

---

## 🚀 Live Demo & Usage

1. Open `index.html` in any web browser.
2. Tap **"Wake The Universe"** to enter the sanctuary.
3. Tap constellation stars to view memory cards.
4. Toggle ambient soundscapes using the bottom sound deck.
5. Hold **"HOLD TO BLOW OUT THE STARS"** to trigger the sleep mode blackout sequence.

---

## 🛠️ Tech Stack

- **3D Graphics**: Three.js WebGL Engine
- **Animations**: GSAP (GreenSock)
- **Audio**: Web Audio API (AudioContext, Oscillators, Biquad Filters, Noise Generators)
- **Styling**: Vanilla CSS3 Glassmorphism & Modern Typography (Cinzel Decorative, Space Grotesk, Plus Jakarta Sans)
